# Doppelkopf-Zettel

Eine kleine Web-App zum Mitschreiben beim Doppelkopf-Abend — für vier oder fünf Spieler,
komplett offline-fähig, alle Daten bleiben im Browser (localStorage).

## Funktionen

- **Heute**: Abend starten, Runden mit Sieg/Niederlage/Aussetzen antippen, Solo-Erkennung,
  laufender Punktestand mit Aufgeh-Kontrolle, Bierkasse (Cent pro Minuspunkt)
- **Alltime**: Rangliste über alle Abende, Tagessiege, eingezahlte Bierkasse
- **Nachtragen**: Alte Abende mit Endständen nachträglich erfassen
- **Sichern**: Stand als Text exportieren/importieren (z. B. bei Handywechsel)

## Nutzung

Einfach `index.html` im Browser öffnen — keine Installation, kein Server, keine Abhängigkeiten.

Am Handy: Seite öffnen und über „Zum Home-Bildschirm hinzufügen" wie eine App nutzen.
